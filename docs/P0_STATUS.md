## 安全处理

- `.env`、商户私钥、证书、订单 JSON、统计 NDJSON 均在 `.gitignore` 中。
- 管理订单和 Dashboard 接口要求 `X-Admin-Token`。
- 微信支付/退款回调校验时间戳、平台证书序列号、RSA-SHA256 签名后才解密业务数据。
- CI 会检查 PHP/JS/JSON 语法，并阻止典型密钥/运行文件进入仓库。

这是一份 **P0 开发预览 / Draft**，不是可直接替换生产站的最终发布包。现网支付密钥和证书不进入 GitHub，部署时继续由服务器环境提供。
