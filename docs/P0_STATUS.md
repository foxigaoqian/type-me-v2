## 算法冻结与校准

- 正式算法：`campus-zscore-v1`，定义见 `config/algorithm-v1.json`。
- 旧直接累加算法在 30 万组中性随机样本中有明显结构偏差；标准化算法同样模拟后八人格约落在 11.75%–13.73%。
- GitHub CI 固定运行 5 万组分布守门测试，允许中性模型 8%–18% 的宽区间；这只检测算法先天偏置，不要求真实用户结果平均。
- 浏览器 fallback 与服务端使用同一算法。
- `config/v2.json` 中旧的 provisional scoring note 已更新为 frozen algorithm 说明。

## 安全处理

- `.env`、商户私钥、证书、订单 JSON、统计 NDJSON 不提交 Git。
- 私有订单/分享/统计镜像写到 Web 根目录之外；Web Server 同时阻止敏感路径访问。
- Dashboard / 管理接口使用 `ADMIN_TOKEN`。
- 支付/退款回调验签后才解密业务数据。
- 订单数据库使用 InnoDB 事务 + `SELECT ... FOR UPDATE` 锁 SKU，避免并发超卖；主动查单与支付回调共用幂等 finalize。
- CI 检查 PHP/JS/JSON、人格算法分布、Vercel 容器、MySQL migration、192 SKU、库存事务以及 4 人宿舍 HTTP 流程。
