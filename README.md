# TYPE ME V2

大学生人格测试 + 人格身份表达 + 人格 T 恤。

## V2 核心路径

`Landing → 12题测试 → 主人格 + 隐藏人格 → 完整结果 → 人格身份证 → 分享裂变 → 人格T恤 → 下单支付`

本仓库基于当前线上 H5/PHP 系统改造，不重写现有微信支付、订单、退款底座。

## 分支

- `main`: 安全基线，不提交真实密钥、证书或运行数据
- `v2-development`: V2 P0 开发

## 本地/服务器要求

- PHP 8.x（建议）
- `curl`
- `openssl`
- Web 服务器可将 `/api/*` 路由到 PHP
- 生产支付需在服务器放置 `.env` 与 `certs/apiclient_key.pem`，这些文件不会进入 Git

## 配置

复制 `.env.example` 为 `.env`，填写服务器真实配置。不要提交 `.env`。
